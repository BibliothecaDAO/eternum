# `char.json`: the character spec

One file per character holds every decision the bind tools need. Nothing character-specific lives in a script. Paths are
absolute or relative to the baseline folder (the folder that holds `tools/`). The working example, the Knight's
`../t1-knight-claude/v4/char.json`, is in the author's working tree and is not shipped. With a Windows build of Blender
run from WSL, write absolute paths in Windows (UNC) form.

Start a new troop by copying that file, pointing it at the new packet and raw mesh, and emptying `labels.overrides`,
`labels.refine_by_colour` and `labels.patches`. Fill them in as the label sheets and the seam audit show what the
character needs.

## Top level

| Key            | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`         | Free text, shown in reports                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `raw_glb`      | The raw generated mesh. Never edited                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `packet`       | The view packet's folder                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `views`        | `front`, `back`, `left`, `right` view images inside the packet. `left` is the profile whose nose points to image-left                                                                                                                                                                                                                                                                                                                                                                                                             |
| `manifest`     | The packet manifest with the landmarks                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `work`         | Working folder for this character                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `helpers`      | Helper joints, e.g. `["elbow_half", "knee_half", "upperarm_twist"]`. `upperarm_twist` only for troops with shoulder plates                                                                                                                                                                                                                                                                                                                                                                                                        |
| `pose_sets`    | The troop's own pose sets, e.g. `["knight"]`. The general set and the range-of-motion set are always used                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `review_poses` | The troop's stances for the joint sheets, e.g. `["knight:guard-middle", "knight:cut-windup"]`. Choose the ones the game will show most                                                                                                                                                                                                                                                                                                                                                                                            |
| `build_from`   | Optional. File stem under `work` of the mesh the build starts from, when an approved mesh edit has made a later source than `character-bored` (the mesh as imported and bored). Each such edit is listed under `edits` with its tool, its report and the approval it rests on                                                                                                                                                                                                                                                     |
| `gear`         | Optional. The character's gear spec (path under `human-baseline`). With it the gate fits the items to their sockets, checks them and renders them. See "Gear spec"                                                                                                                                                                                                                                                                                                                                                                |
| `reduce`       | Optional. `mouths`: plates that are tubes round a limb and open at an end the limb's bulk fills in the bind (a bracer's elbow end), e.g. `["bracer_l", "bracer_r"]`; each open rim of them is closed at every level of detail (`hb_reduce.py`). `mouth_tone`: how dark the closure is painted against the plate's lining (default 0.6). Name a plate here when `hb_gap_check.py` on a reduction flags holes at its joint that the bind does not have                                                                              |
| `bake`         | Optional. `unwrap` (`"inherit"`, default: the bind's texture pieces kept where a reduced face lies on one; `"smart"`: everything projected afresh), `density` (`{"class": share}`: texel density of a class against the rest; generated surface defaults to 0.45), `orm_rules` (the family's roughness and metallic corrections; defaults in `hb_bake.py`), `orm: "keep"` for a source already corrected, `normal_max_tilt` (degrees, default 50), `cover_reach`, `show_reach`, `show_near` (metres; defaults 0.010, 0.03, 0.012) |
| `runtime_fit`  | Optional. `hands.<hand class>.index_toward`: the working-frame direction along a fist's knuckle row toward the index finger, for a hand with no bored guide whose mirror image is not the other hand. `thumb_side`: the working-frame direction a hanging fist's thumb points (default forward)                                                                                                                                                                                                                                   |
| `labels`       | See below                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

## `labels`

| Key                | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `legend`, `id_png` | The packet's legend and one flat-colour ID map per view                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `overrides`        | Per-class decisions, `{"class name": {...}}`. Keys in the next table                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `padding_texture`  | The class whose texture shoulder padding takes (the leather the plate is worn over)                                                                                                                                                                                                                                                                                                                                                                                                          |
| `refine_by_colour` | Classes whose borders move onto the texture's colour boundary: a list, or `{"class": [classes it may trade faces with] or null}`. Name every rigid piece and every stiff over-garment                                                                                                                                                                                                                                                                                                        |
| `patches`          | Hand corrections where the ID maps put a class on the wrong piece: `[{"box": [x0, y0, z0, x1, y1, z1], "from": ["class"], "to": "class", "why": "..."}]`, metres in the working frame. `to` may name a class the legend lacks if the patch describes it: `"class": {"kind": "soft", "region": "head"}` (a `neck` class for the throat, see below). `"facing": [x, y, z, c]` keeps only faces whose normal is within arccos(c) of that direction (the underside of a jaw: `[0, 0, -1, 0.35]`) |
| `snap`             | Borders of rigid pieces onto the crevice where they meet their neighbours. Default on; `false`, or a list of classes                                                                                                                                                                                                                                                                                                                                                                         |
| `clean_rims`       | Mixed labels in the strip round rigid pieces. Default on                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `inpaint_hidden`   | Surface hidden at rest under or beside a piece (within 15 mm of a rigid border, or in a crevice) takes the colour of its nearest visible surroundings. Default on                                                                                                                                                                                                                                                                                                                            |
| `repaint`          | `{"class": {"from": "class", "tone": 0.7}}`: every face of the class takes one plain texel of the other class's colour. Changes the rest pose; only with the user's approval. For a throat with a painted shadow under the chin: `{"neck": {"from": "head", "tone": 0.7}}`                                                                                                                                                                                                                   |
| `cuff_texture`     | `"plain"` (default): a cuff through a wrist seam is one plain colour of the garment it continues, from its lighter tones (`cuff_tone`, default 0.65). `"garment"`: laid out from the garment's own texture                                                                                                                                                                                                                                                                                   |
| `seam_sides`       | Where a body part meets another rigid piece in a closed seam (hand and bracer), body-part faces on the underside of the other piece's overhanging lip go to that piece. Default on (`"lip"`); `"plane"` moves everything beyond the seam's plane; `false` turns it off                                                                                                                                                                                                                       |

## Per-class keys in `labels.overrides`

| Key                     | Meaning                                                                                                                                                                                                                                          | Use for                                                                                               |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| `kind`                  | `rigid` or `soft`                                                                                                                                                                                                                                | Correcting the legend                                                                                 |
| `bone`                  | The joint a rigid class follows. May be a helper joint                                                                                                                                                                                           | Shoulder plates: `upperarm_twist_l` / `_r`. A buckle on the belt's joint, not the chest plate's       |
| `region`                | `torso`, `arm`, `leg`, `head` for a soft class                                                                                                                                                                                                   | Only where position alone is ambiguous                                                                |
| `underlay`              | `"full"`: the piece lifts off what it covers. Built as a closed shell over padding. `"tube"`: the piece's rim runs right round a limb; under it goes a tube that narrows from the rim into the piece, with a skirt closing the piece's underside | `"full"`: shoulder plates. `"tube"`: helmets and heads (the tube is the neck)                         |
| `tube_scale`            | How far a tube narrows, as a share of the rim's outline (default 0.62)                                                                                                                                                                           | A neck much thinner or thicker than 0.62 of the helmet's rim                                          |
| `lining`                | `true`: the piece gets an inner side (itself again, 1.2 mm inside, facing inward). Pieces with `"underlay": "full"` always have one                                                                                                              | Any plate whose edge lifts off the body and shows its inside: a greave's knee top                     |
| `underlay_width`        | How far the body continues under the piece's rim, metres (default 0.03). It must exceed how far the body leaves the piece in the deepest pose, or the strip's inner edge comes out                                                               | Helmets: 0.055. Greaves with knee tops: 0.06                                                          |
| `underlay_colour`       | Class whose colour the underlay takes                                                                                                                                                                                                            | Skin under a helmet and round the head: `"head"`                                                      |
| `underlay_colour_depth` | Metres in from the rim where that colour starts (default 0.012)                                                                                                                                                                                  | 0 under a helmet                                                                                      |
| `underlay_tone`         | Which tone of the `underlay_colour` class to take, as a share of the way from its darkest to its lightest face (default: the median)                                                                                                             | Skin under a helmet: 0.7. A face's median includes its shadows and reads as leather over a whole neck |
| `follow_arm`            | `false`: the class is barred from the arm joints                                                                                                                                                                                                 | Stiff over-garments: cuirass, vest, their straps                                                      |
| `over`                  | The garments the class lies over. Its border with them gets a smooth cut                                                                                                                                                                         | The same over-garments, naming the sleeves                                                            |
| `forbid_joints`         | Joints the class may never follow                                                                                                                                                                                                                | Collar, cuirass and straps: `["Head"]`                                                                |
| `fill_colour`           | Class whose texture a cuff through this piece's seam takes                                                                                                                                                                                       | Only if the automatic choice (the soft class the piece touches most) is wrong                         |

## Gear spec

`{"items": [ … ]}`, one entry per removable item (`tools/hb_gear.py`). Every item: `name`, `blend` and `object` (where
its mesh is), `joint` (the one joint it follows), `fit`, `ignore_classes` (the classes it is allowed to touch: the hand
that holds it, the bracer it is strapped to), `aim` (which of its own axes a pose's direction names, e.g.
`{"blade": "+Z"}` or `{"face": "-Y"}`), and optionally `allow` (limits that replace the defaults in
`harness/thresholds.json`, `equipment`).

| `fit`     | For                                   | Keys                                                                                                                                                                                                                            |
| --------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `grip`    | A handle in a fist with a bored guide | `guide` (the bore report), `hand_class`, `blade_toward` (working-frame direction the blade leaves the fist), `blade` and `edge` (item axes), `grip_half` (origin to the guard's inner face, metres), `grip_radius`, `guard_gap` |
| `forearm` | A plate strapped to a forearm         | `wrist_joint`, `surface_classes` (what it sits on), `outward` (working-frame direction away from the body), `centre_from_wrist`, `radius`, `clip` (how far the rear may sink, default 1 mm), `front` and `up` (item axes)       |
| `socket`  | Anything placed by hand               | `matrix` (4×4 in the working frame at rest)                                                                                                                                                                                     |

Example: `../t1-knight-claude/v4/gear.json`.

## What to decide for each new troop

1. **Seam audit first** (`tools/hb_seam_audit.py`). Every rigid-on-rigid seam is either a closed loop the bind can run a
   cuff through, or a design fault.
2. **Which classes are stiff over-garments.** Anything of leather or padding worn over a sleeve: `follow_arm: false`,
   `over: [sleeves]`, `forbid_joints: ["Head"]`.
3. **Head and helmet.** `underlay: "tube"`, `underlay_colour: "head"`, depth 0, width 0.055 for a helmet.
   `forbid_joints: ["Head"]` on whatever the helmet's rim rests near. **The throat.** A packet's `head` class usually
   runs down the front of the neck to the collar. Rigid on the head, that strip swings out as a flap under the chin when
   the head tips back. Patch everything below the jaw to a soft class:
   `{"box": [...], "from": ["head"], "to": "neck", "class": {"kind": "soft", "region": "head"}}`, and the underside of
   the jaw with a second patch that has `"facing": [0, 0, -1, 0.35]`, so the seam lies on the jaw's own edge and not on
   a level line across the throat. Better still, have the packet label the neck as its own soft class.
4. **Knee tops and other rims the body travels out of**: `underlay_width` 0.06 and `lining: true`. Check the knee at 90
   and 135 degrees from the front. 4b. **Shoulder plates**, if any: `underlay: "full"`, `bone: upperarm_twist_*`, and
   `upperarm_twist` in `helpers`. **Plates with a free edge** (a greave's knee top): `lining: true`. The gate's hole
   check says which plates need one.
5. **Label sheets in label colours** at every joint, at rest and with the joint bent, and a look under every lifted rim
   from behind and below (`rt-back-low`, `rt-back-right`, `rt-back-left` are views the renderer knows). Patch what sits
   on the wrong piece; name the pieces to refine by colour. Anything of one piece's colour that lifts off, stays behind
   or sticks out when the joint bends is a label on the wrong piece: a tab of collar labelled helmet goes up with the
   helmet.
6. **Review poses.** The three or four stances the game will show most.
7. **Equipment**, once the bind is approved: a gear spec (above) and `"gear"` in the spec. Fit first, at rest, and read
   the close-ups; note the blade's angle to the forearm, because it says which poses the grip can do. Then give every
   item in the troop's pose set a place and a direction (`"at"` and the direction in each pose's `items`), solve the
   arms (`tools/hb_item_aim.py --fix --place`, then `--fix --hold --clear`), measure on the real meshes
   (`tools/hb_gear.py`), render the set with the items on from two sides, and read every pose against its own
   description. Restate a description the grip cannot meet; do not let the solver meet it with a wrung arm.
8. **Levels of detail**, once the equipment is approved: reduce (`tools/hb_reduce.py`), tuck, and run all four checks on
   each level (`hb_lod_see.py`, `hb_lod_backs.py`, `hb_lod_check.py`, and `hb_gap_check.py` on the reduced file). Holes
   at a joint that the bind does not have mean a plate round that limb has an end the limb no longer fills: name it
   under `reduce.mouths`. Then bake, and look at the levels beside the bind in the game's own views (from above, front
   and back, in a walk) before exporting.

Then run `tools/hb_gate.py --build`. Change the spec, not the tools, until the battery and the independent review pass.
A tool change is a baseline change: make it in the baseline, with the evidence, and re-run every troop that is not yet
approved.
