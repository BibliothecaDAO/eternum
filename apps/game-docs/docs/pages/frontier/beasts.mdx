# Beasts

Every guard above the Deep belongs to one of {FRONTIER.beastFamiliesCount} families. The beast species changes as you go
deeper, while its mark and reward stay the same. Camp, rift, herd, and band guards double in size on each deeper layer,
with each site rolling a guard size inside its layer range below. Ruin guards follow the ruin's relic tier instead.
