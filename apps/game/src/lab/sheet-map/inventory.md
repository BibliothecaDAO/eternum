## Proposed map scope

`MAP_SHEET` in `src/tokens.ts` derives ownership from **the same `HUD_SHEET`**: you gold, ally teal, enemy coral,
neutral and unowned stone. `mapAgeAccent()` reads `HUD_MODES`: Blitz `#e8a65a`, Frontier `#b49cf0`, Eternum `#e6c27a`.
No map-only colour palette. Age indicates intent/selection; coral means hostile/refused; teal means transfer. Ownership
does not change with age. State symbols and endpoint chevrons supplement colour.

Proposal: selected fill .12, destination .18, range .04; cased ground rings (radii .96–.98, casing .018, opacity .9);
route core .045 world units inside a .09 casing, opacity .9 (preview .45); site glyph .85; age fog-edge cue .025 wide at
.16 opacity. Existing native hover pulse and shipped fog remain. Paths are static: no constant flowing animation. The
lab's symbols and site anchors are appearance specimens, not new gameplay rules or new production markers.

Cost: one section of the shared HUD sheet, fixture, presentation adapter, proof runner, inventory and tests. No separate
map sheet or route. No new live setting, render pass, state store, model or texture asset. Cased rings and path ribbons
add lab geometry; a production conversion would batch it in the existing managers. This phase makes **no production
performance claim** and migrates no live caller.

## Shared lab placement

Owner refinement (18 October): the 3D comparison lives inside **Map context** at `/lab/kit`, beside the DOM examples, on
`ux/stylesheet`'s token system. **Open 3D comparison** mounts the native terrain; **Close 3D comparison** disposes it.
There is no standalone `/lab/sheet-map`. All four columns stay visible together and share the shipped terrain, lighting,
fog mask and assets. The minimap samples use the existing HexMarker and biome-colour resolver; their colour key is not a
second minimap navigation implementation.

The DOM minimap can read `--hud-map-explored` and `--hud-map-fog`, installed by `hudVariables()`. They come from
`MAP_SHEET.minimap.explored` (`rgb(var(--hud-ink) / 0.1)`) and `.fog` (`var(--hud-well)`), so they still follow the HUD
editor's ink and well. Ownership continues to use `--hud-own/ally/enemy/neutral`.
