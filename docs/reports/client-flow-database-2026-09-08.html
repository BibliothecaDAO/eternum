Failure classes each is one root cause behind several flows

F1
Every task is a surface.
Twenty-five overlay surfaces. Build, Military, Production and Logistics are windows, not panels: 1320 px wide, full height, over the map. Flows R2, R5, R6, R9 to R14, M1 to M3, M10.
Fix the class: a task that ends with a map click never opens a window. It opens a compact picker next to what was clicked, and the map click completes it.
F2
Outside click dismisses.
The popover primitive closes on any pointer-down outside it. A panel cannot stay open while the player points at the map, so every choose-then-place flow fights the dismissal. This is why army deploy direction was moved into a miniature map inside the modal.
Fix the class: a surface that is waiting for a map click declares it, and map pointer-down completes the task instead of dismissing. One rule in the primitive, every flow inherits it.
F3
The real map is duplicated inside panels.
The army creation body carries its own hex map to pick a direction. Build, Military and Production each carry a structure sidebar to pick a realm, duplicating the left realm list. The map paths exist (M1b, M1c, M2b, R2b, R5c) and every one of them ends in the window: the map only pre-fills it.
Fix the class: the realm is the selection, the direction is a hex on the world map. The right-click create path already exists and needs only an affordance: a ring of deployable hexes when a structure is selected.
F4
Action mode paints the whole map.
Rings on every owned entity, a pulsing banner at the bottom, and "Press Esc" as the first instruction.
Fix the class: highlight only the selection and its legal targets. The hover tooltip is the instruction; the banner goes.
F5
Dead ends and late errors.
"Need Resources" is a disabled button. "Insufficient resources to build here" is a toast after the plot click, although the cost was known before it.
Fix the class: a blocked action names the shortfall and offers the nearest way to close it, before the click.
F6
Three clocks.
Day tick progress with a percent, the start countdown, the end timer.
Fix the class: one clock with the minute tick on its bar.
F7
Icons without words.
The quick actions row and the army readiness icons carry labels only for screen readers.
Fix the class: a label under every icon a player has to learn.
F8
Automation is buried.
Production automation is three levels down; transfer automation is a tab and then an advanced modal.
Fix the class: one automation row per realm in the left panel, with the preset as a switch. Details open only when the switch is set to custom.
F9
Labels and models carry the same job twice.
The owner's name is on every unit; the army model is one figure at one scale whatever the count.
Fix the class: the label ladder from issue #4876, and army models per size bucket in the Model Lab.
F10
Eternum machinery leaks into Blitz and spectators get a stripped player HUD.
Hyperstructure shares are auto-allocated in Blitz by a hidden manager; the market, faith, tribes and villages exist as code paths the Blitz player never sees but the surfaces are built around; a spectator gets the player layout with pieces removed and no lord to follow (V2, V7).
Fix the class: one layout whose surfaces are declared per mode and per role, rather than branches inside each component.
Two things the client already does right and the iterations build on: movement is one right-click with a cost tooltip, and the right-side tile panel is the correct contextual surface for the selection.

Iterations one flow each, measured in clicks and map visibility

  1. Finish the map path for army creation. M1c already gets realm and direction from the map and then opens the window. Replace the window at the end of that path with a compact picker at the hex: tier chips, count, confirm. Label the deployable hexes so the path is discoverable. Target: three clicks, map visible. Closes M1 and M2 for the common case; the window stays for browsing armies.
  2. Popover keeps open for a map click. The primitive gains one declared state: waiting for the map. Closes F2 for every choose-then-place flow.
  3. Build from the plot. Click a plot, a compact building picker anchored at it, click a building, placed. The 1320 px window survives only for browsing. Closes R2.
  4. Action mode scoped to the selection. Rings on the selection and its legal targets only, banner deleted. Closes F4.
  5. Blocked actions explain themselves. Upgrade and build name the shortfall and the nearest stock before the click. Closes F5.
  6. One clock. Closes F6.
  7. Labels on the ladder. Reuses the quiet labels built in the lab. Closes half of F9.
  8. Models by size. Figure count per troop bucket in the Model Lab. Closes the other half of F9.
  9. Automation as a switch per realm. Closes F8.
  10. Words under icons. Closes F7, and it can ride along with any earlier iteration that touches the row.
